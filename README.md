# syuwasyiwa

手話を体系的に学べるツール

## 手話ミラー / Shuwa Mirror

「おはよう」「ありがとう」など、**動きのある手話の単語**をお題にして、
**お手本動画（参考）を見ながら**、自分の手をカメラの**鏡**で確認して覚えられる
学習アプリです。手指トラッキング（MediaPipe Hand Landmarker）で手のスケルトンも
重ねて表示します。明るく親しみやすいUIで、1つずつ・テストつきで身につきます。

### 学びの流れ

1. **レッスン** — お題の手話が1つずつ出題され、お手本動画＋動きのヒントを見ながら、
   鏡に映る自分の手でまねして覚えます。
2. **テスト** — お題（単語）だけが出て、手で表現 → 「お手本を見る」で答え合わせ →
   自己採点（◯／△）。最後にスコアが出ます。
3. おぼえた手話はブラウザに記録され、ホームの進捗バーに反映されます。

### 収録ジャンル

- **あいさつ**：おはよう／こんにちは／こんばんは／ありがとう／ごめんなさい／よろしくお願いします
- **まいにちの どうさ**：たべる／のむ／いく／すき
- **じこしょうかい**：わたし／なまえ
- **いろ**：あか

### 特徴

- ▶ **お手本動画** — 各単語に YouTube の参考動画を埋め込み（動き＝画像で確認）
- 🪞 **鏡ミラー＋手指トラッキング** — 自分の手を鏡像で映し、21点のスケルトンを重ねて描画
- ✏️ **1つずつのレッスン** ／ 🏅 **ランダム出題のテスト＋スコア**
- 🎨 **明るい学習向けUI** — 白基調＋やさしい配色・大きな文字・丸いボタン
- 💾 **進捗の保存**（localStorage） ／ 🔒 **映像は端末内だけで処理**

### 使い方

ビルド不要です。HTTPS（または `localhost`）でこのフォルダを配信してください。
カメラ API はセキュアコンテキストでのみ動作します。

```bash
# 例: Python の簡易サーバー
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. ホームで「レッスン」または「テスト」を選びます。
2. カメラの使用を許可すると、自分の手が鏡のように映ります（許可しなくてもお手本は見られます）。
3. レッスンはお手本をまねて「できた！つぎへ」、テストは「お手本を見る」で答え合わせします。

> 手指トラッキングのモデルと WASM、お手本動画は外部（jsdelivr / Google / YouTube）から
> 読み込みます。利用にはネットワーク接続が必要です。

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル |
| `app.js` | 画面遷移・レッスン／テストの進行・お手本動画・カメラ／手指トラッキング |
| `signs.js` | 手話単語のデータ（自由に追加・修正可能） |

### 単語の追加

`signs.js` の配列に項目を追加するだけで増やせます。

```js
{
  word: "また あした",          // 表示する語（\n で改行可）
  reading: "mata ashita",
  category: "あいさつ",
  steps: "うごきのヒント…",
  video: "YouTubeの動画ID",      // null なら検索リンクをお手本にする
  search: "手話 また明日 やり方", // 「ほかの動画を探す」用キーワード
}
```

> ⚠️ お手本は YouTube の**参考動画**です。手話は地域や人によって表現が異なる場合があります。
> 動きのヒントは学習の手がかりで、正確な動きは必ずお手本動画で確認してください。
