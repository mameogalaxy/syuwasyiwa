# syuwasyiwa

手話を体系的に学べるツール

## 手話ミラー / Shuwa Mirror

Webカメラに映る自分の手を**鏡のように**見ながら、手話・指文字を練習できるブラウザアプリです。
手指トラッキング（MediaPipe Hand Landmarker）で手のスケルトンを重ねて表示し、
伸びている指の本数も検出します。指文字リファレンスを見ながら、同じ手の形を作って練習できます。

### 特徴

- 📷 **鏡像表示** — カメラ映像を左右反転し、鏡と同じ感覚で手の形を確認
- ✋ **手指トラッキング** — 21点の手のランドマークをリアルタイムに重ねて描画（最大2手）
- 🔢 **指の本数検出** — 左右の手で伸びている指を判定して表示
- あ **指文字リファレンス** — 指文字カードを選ぶと手の形のヒントを表示
- 🖼️ **スナップショット** — スケルトン付きの静止画をPNGで保存
- 🔒 **プライバシー** — 映像はブラウザ内だけで処理され、サーバーへ送信されません

### 使い方

ビルド不要です。HTTPS（または `localhost`）でこのフォルダを配信してください。
カメラ API はセキュアコンテキストでのみ動作します。

```bash
# 例: Python の簡易サーバー
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. 「▶ カメラを開始」を押してカメラの使用を許可します。
2. 手をカメラに向けると、スケルトンと指の本数が表示されます。
3. 右の指文字カードを選び、説明を見ながら同じ手の形を作って練習します。

> 手指トラッキングのモデルと WASM は CDN（jsdelivr / Google）から読み込みます。初回はネットワーク接続が必要です。

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル |
| `app.js` | カメラ制御・手指トラッキング・描画・スナップショット |
| `fingerspelling.js` | 指文字リファレンスのデータ（自由に追加・修正可能） |

### リファレンスの追加

`fingerspelling.js` の配列に項目を追加するだけで指文字カードが増えます。

```js
{ char: "ち", reading: "chi", desc: "手の形の説明…" }
```

指文字の説明は練習の手がかりです。正確な形は地域や手話通訳者によって異なる場合があります。
