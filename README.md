# syuwasyiwa

手話を体系的に学べるツール

## 手話ミラー / Shuwa Mirror

Webカメラに映る自分の手を**鏡のように**見ながら、お題に合わせて指文字を1つずつ
覚えていける学習アプリです。手指トラッキング（MediaPipe Hand Landmarker）で
手のスケルトンを重ねて表示し、明るく親しみやすいUIで学べます。

### 学びの流れ

1. **レッスン** — お題が1つずつ出題され、ヒントを見ながら手で形を作って覚えます。
2. **テスト** — お題だけが出て、手で表現 → 「答えを見る」で答え合わせ → 自己採点。
   最後にスコアが出ます。
3. おぼえた指文字はブラウザに記録され、ホームの進捗バーに反映されます。

### 特徴

- ✏️ **1問ずつのレッスン** — 順番にこなして無理なく定着
- 🏅 **テストモード** — ランダム出題＋スコアで力だめし
- 📷 **鏡像ミラー** — カメラ映像を左右反転し、鏡と同じ感覚で手の形を確認
- ✋ **手指トラッキング** — 21点の手のランドマークをリアルタイムに重ねて描画
- 🎨 **明るい学習向けUI** — 白基調＋やさしい配色・大きな文字・丸いボタン
- 💾 **進捗の保存** — おぼえた数を端末内（localStorage）に記録
- 🔒 **プライバシー** — 映像はブラウザ内だけで処理され、サーバーへ送信されません

### 使い方

ビルド不要です。HTTPS（または `localhost`）でこのフォルダを配信してください。
カメラ API はセキュアコンテキストでのみ動作します。

```bash
# 例: Python の簡易サーバー
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. ホームで「レッスン」または「テスト」を選びます。
2. カメラの使用を許可すると、自分の手が鏡のように映ります（許可しなくてもお題は練習できます）。
3. お題に合わせて手で形を作り、レッスンは「できた！つぎへ」、テストは「答えを見る」で進めます。

> 手指トラッキングのモデルと WASM は CDN（jsdelivr / Google）から読み込みます。初回はネットワーク接続が必要です。

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル |
| `app.js` | 画面遷移・レッスン／テストの進行・カメラ制御・手指トラッキング |
| `fingerspelling.js` | 指文字リファレンスのデータ（自由に追加・修正可能） |

### リファレンスの追加

`fingerspelling.js` の配列に項目を追加するだけで指文字カードが増えます。

```js
{ char: "ち", reading: "chi", desc: "手の形の説明…" }
```

指文字の説明は練習の手がかりです。正確な形は地域や手話通訳者によって異なる場合があります。
