# MECHA HENSHIN — インカメラAR変身アプリ

スマホのインカメラを起動し、画面の **「変身」ボタン** を押すだけで、顔にメカパーツが
次々と装着されていくブラウザ製ARアプリです。顔認識で目・鼻・口・輪郭の位置を検出し、
そこに合わせて金属パーツ・フェイスガード・クラウン（ヘルメット）・発光バイザーが
「ウィーン」「カシャン」という機械音とともにスライド・回転・合体し、最終的に
ヒーロースーツのようなフルフェイスマスクが完成します。

## 特長

- **インストール不要** — モダンブラウザだけで動作（インカメラ + HTTPS）。
- **顔追従AR** — MediaPipe Face Landmarker で顔の座標フレームを構築し、
  目・あごの位置を EMA スムージングしてズレ・ジッタを抑えつつ、パーツが
  顔の動き・傾きに自然追従。
- **映画的な段階変身（約3.5秒）** — パーツが顔の外から飛来し、回転・スライド・
  展開しながら装着され、最後にマスクが合体・起動します。
  1. **目元スキャン** — ターゲティングビームが目の上を走査（スキャン音）
  2. **頬アーマー** — 左右から飛来してロック（ウィーン→カチッ＋画面揺れ＋火花）
  3. **クラウン展開** — 上から回転しながら着地（カチッ）
  4. **あごロック** — 下から合体（ガシャン＋揺れ＋発光）
  5. **フェイスプレート合体** — 左右の半割が中央でスナップ（フラッシュ＋火花リング）
  6. **バイザー装着 → 目元発光（イグニッション）**
  7. **HUD 起動** — ターゲットリング・スキャンライン・テレメトリ点灯
  8. **完成** — エネルギーシーム発光・粒子リング・ファンファーレ
- **立体的な金属表現** — ドロップシャドウ＋ブラッシュドメタルのグラデーション＋
  上面シーン光＋ベベル縁＋装甲パネルライン＋発光ライン＋リベットで、平面画像
  ではない質感を 2D Canvas で表現。
- **演出エフェクト** — ロック音・画面揺れ・発光フラッシュ・粒子バースト・
  完成後の HUD（リング／スキャンライン／微粒子）。
- **効果音はすべて Web Audio で生成** — 音声アセット不要。
- **黒・銀・青白発光** を基調としたオリジナルの近未来ヒーロー級マスク
  （角ばったラップアラウンドバイザー＋鋭い発光アイ、センタークレスト、
  ウィドウズピークのブロウ、ノーズリッジ、縦スリットのマウスグリル、
  テンプルインテーク、二トーンの金属トリム）。
- **シネマティックな解除** — 「解除」ボタンで、目元とHUDがパワーダウン →
  パーツが逆順に外れて飛び去る分解アニメ（音・揺れ・粒子つき、約1.5秒）。
- **8種の変身マスクから選択** — 画面下のストリップで切替:
  🤖メカ / 👺天狗 / 😊おかめ / 🧛バンパイア / 🧟ゾンビ / 💩うんこ / 🌳木 / 🐜アリ。
  どのマスクも「パーツが飛来して合体」する共通エンジンで動作。
- **写真撮影** — 📷ボタンでAR合成のスナップを撮影し、保存／共有
  （対応端末では `navigator.share`、非対応ならダウンロード）。
- **将来拡張**: パーツは「顔空間」座標で記述しているため、各パネルを
  3D メッシュへ差し替える拡張が容易な設計。マスク追加は `js/masks.js` に
  パーツ定義を足すだけ。

## 使い方（ローカル）

カメラ API はセキュアコンテキスト（`localhost` または HTTPS）が必要です。

```bash
# 任意の静的サーバでこのディレクトリを配信
python3 -m http.server 8000
# → http://localhost:8000 をスマホ/PCのブラウザで開く
```

スマホ実機で試す場合は HTTPS が必要です（例: ngrok などのトンネル、
または HTTPS 対応の静的ホスティングへデプロイ）。

1. 「カメラを起動」をタップし、カメラ利用を許可。
2. 顔を画面に合わせ、ステータスが `READY` になったら **「変身」** を押す。
3. パーツが合体してフルフェイスマスクが完成。「解除」で元に戻ります。

## 技術構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構成（カメラ canvas / HUD / コントロール / 起動ゲート） |
| `css/style.css` | HUD・ボタン・起動画面のスタイル |
| `js/main.js` | カメラ起動、MediaPipe 読み込み、平滑化、描画ループ、マスク選択、写真撮影 |
| `js/gfx.js` | 顔座標フレーム＋共通描画プリミティブ（金属/着色シェイプ/発光等） |
| `js/masks.js` | 8種のマスク定義（パーツ形状・配色・飛来設定・タイミング） |
| `js/transformer.js` | 組み立て／解除シーケンスとエフェクトを駆動する汎用エンジン |
| `js/effects.js` | 粒子・画面揺れ・フラッシュ・完成後 HUD |
| `js/sound.js` | Web Audio による機械音／効果音の生成 |

顔認識モデルと WASM は CDN（jsdelivr / Google MediaPipe）から読み込みます。
オフライン環境ではこれらをローカルへ同梱してパスを差し替えてください。

## 動作要件

- インカメラ付きデバイス
- WebGL / Web Audio / ES Modules 対応のモダンブラウザ
- セキュアコンテキスト（`localhost` または HTTPS）
- モデル取得のためのネットワーク接続（初回ロード時）
